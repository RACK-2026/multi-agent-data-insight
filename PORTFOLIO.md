# Portfolio Notes

## Resume-ready summary
Privacy-safe multi-agent analytics demo built with FastAPI and Vue 3. It turns structured data into a traceable workflow with specialized analysis agents, independent review, prompt optimization, and local persistence.

## Highlights

- Designed an orchestrator/reviewer/optimizer workflow with structured outputs.
- Added validation, prompt versioning, API documentation, and local SQLite persistence.
- Reworked the public edition to use synthetic data and optional user-supplied model credentials.

## Interview focus
Explain task decomposition, failure handling, reviewer feedback loops, and how private integrations were replaced by optional adapters.

## Public-scope boundary
This repository is a portfolio demo. It contains no company data, credentials, customer records, or proprietary business rules.
